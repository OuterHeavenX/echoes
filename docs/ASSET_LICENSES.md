# ASSET LICENSES

Every external asset used by Echoes of the Last Dawn, with source,
author, license, attribution, and modifications. If an asset is not
listed here, it is original to this repo.

## Original (this repo, no attribution required)
- All character/enemy sprites and portraits: generated by
  `tools/gen_assets.py` (Pillow rectangle drawings, original designs).
  Author: this project. License: same as the project.
- All music and sound effects: generated by `tools/gen_assets.py`
  (sine/triangle note sequences, original progressions, not
  arrangements of existing works). Author: this project.
- All dialogue, names, world, and story content: original to this
  project. No Final Fantasy VI (or any other game's) scenes, maps,
  sprites, music, characters, dialogue, logos, or story events are used.

## Third-party: none in v0.2.0-slice
No paid assets, no asset packs, no stock art, no sampled audio.
Godot Engine itself (MIT) is the runtime, not a game asset; the
exported builds embed the Godot engine under its own license, which
does not require in-game attribution.
