# ECHOES OF THE LAST DAWN

An original story-driven 2.5D JRPG in Godot 4.7.2 (Compatibility renderer).
Beneath Asterreach, buried bells keep the seasons in balance. The Meridian
Authority powers cities by extracting the memories stored in those bells —
and villages are starting to forget people who lived there.

**Status: v0.3.0-c1 — Milestone A complete, Milestone B vertical slice
playable (Prologue + Chapter 1: Bellweather and the station undercroft).**
The full 20–25 hour campaign is NOT complete; see docs/PROGRESS.md for the
honest count of what is implemented vs. planned. No FF6 scenes, maps,
sprites, music, characters, dialogue, or story events are used.

## Run

Requires Godot 4.7.2 (pinned; see docs/DECISIONS.md). The binary used here:
`~/workspace/tools/godot/Godot_v4.7.2-stable_linux.x86_64`.

```sh
cd echoes-of-the-last-dawn
godot --path . --import          # first run: imports PNG/WAV assets
godot --path .                   # opens the title screen
```

Or play a built package: `dist/web/index.html` served over HTTP (not
`file://`), or `dist/linux/echoes-of-the-last-dawn.x86_64` (needs the
matching `.pck` beside it).

## Controls

- Move: WASD / arrow keys, left stick / D-pad, on-screen D-pad (touch)
- Interact / confirm: E, Enter, Space, gamepad A, tap Interact
- Cancel: Esc, X, gamepad B
- Menu: Tab, M, gamepad Y
- Map/journal: Q (menu Journal tab in this slice), gamepad Back
- Steam Deck layout intent: stick/D-pad move, A confirm, B cancel,
  X context, Y menu, shoulders tab/party cycling, Menu pause, View journal.
  (Deck hardware check is still pending — see docs/QA.md.)

Touch: landscape-first, left D-pad + right Interact/Menu buttons, battle
commands and targets are directly tappable. `emulate_mouse_from_touch` is
off, so taps do not double-fire as mouse clicks.

## Build

```sh
tools/build.sh   # import + tests + validator + Web + Linux exports + packages
```

Outputs: `dist/web/` (ZIP at `dist/echoes-web.zip`, index.html at root),
`dist/linux/` (tar.gz at `dist/echoes-linux.tar.gz`, executable + .pck).
Checksums are written to `dist/SHA256SUMS` by the build script.

## Project layout

- `scenes/` — title, world (3D Bellweather/undercroft), battle
- `scripts/core/` — Content registry, GameState, SaveMgr, AudioMgr
- `scripts/world/`, `scripts/battle/` — world logic, ATB battle + BattleSim
- `scripts/ui/` — title, dialogue, menu, shop
- `content/` — the authoritative JSON data (characters, jobs, items,
  enemies, encounters, quests, dialogue)
- `assets/` — generated original PNG sprites/portraits, WAV loops
- `tools/` — `gen_assets.py` (deterministic art/audio), `validate_content.py`,
  `build.sh`
- `tests/` — headless battle-math tests, save round-trip scene
- `docs/` — design, campaign, manifest, progress, decisions, QA, release,
  asset licenses

## Saves

3 manual slots + rotating autosave (slot 0), previous save kept as `.bak`.
Same JSON schema (v1) on browser and Linux. Transfer manually: Menu → Save
→ copy export to clipboard, paste into a file, then Title → Import Save.
There is no cloud save. Browser persistence uses Godot's user:// storage;
private browsing or storage restrictions can prevent it — the game shows
a plain error if a save fails rather than pretending it worked.
